# CQA — дизайн-система интерфейса

Визуальный язык повторяет лендинг программы лояльности Freedom Bank (скругления, типографика, цвета, ритм), но без их логотипа, иллюстраций и товарных знаков. У продукта свой знак: градиентный круг с «пузырём-галочкой» и вордмарк **CQA**. 3D-иллюстраций нет: глубина — градиенты, мягкое свечение, слои поверхностей.

**Тон — корпоративная система для руководителей и специалистов контроля качества.** Стиль Freedom применяется сдержанно:

- градиент — только акцент: один lead-заголовок на экран, подсказка плеера, знак продукта; цифры, кнопки и фоны карточек — без градиента;
- пастельные заливки — только там, где несут смысл (роли реплик, статусы), списки — на белом листе;
- приоритет — плотность и читаемость данных: таблица вместо карточек, фильтры с видимыми подписями, единые статусы;
- движение спокойное: без «подпрыгиваний» и декоративных анимаций, только смена прозрачности и короткие transform;
- никаких персонажей, 3D-игрушек и игровых элементов; декор заменён данными (сводка набора, распределения).

Все значения сняты с 10 скриншотов-референсов скриптом на Pillow (медиана пикселей, подгонка радиусов окружностью, ширины «чернил» текста). Скриншоты — retina 2x окна ~1512 CSS px, ужатые до 2000 px: **1 CSS px = 1,32 px изображения** (проверено: разделитель 1 px = 1,3 строки пикселей, отступ 22 px → 16, кегли выходят круглыми 56/32/24/18).

Токены — CSS custom properties в `app.css` (`:root`), тёмная тема переопределяет их на `.cqa[data-theme="dark"]`. Все классы с префиксом `cqa-`, корень `#cqa-root.cqa`.

## Шрифт

**Onest** (Google Fonts, `wght 400..800`, подмножества `cyrillic` + `cyrillic-ext` — все казахские буквы ә ғ қ ң ө ұ ү һ і). Фолбэк: `system-ui, -apple-system, Segoe UI, Roboto, Helvetica Neue, Arial, sans-serif`. Подключение — одна ссылка в `index.html`, стек — токен `--cqa-font`.

Почему Onest: кандидаты (Inter, Inter Tight, Onest, Manrope, Golos Text) отрисованы при той же высоте прописных, что на референсе, и сравнены по ширине надписей «Вопрос-ответ», «Программа», «лояльности», «Как еще повысить кешбэк», «При бесконтактной», вопросов FAQ. Onest 700 совпадает по ширине с заголовками референса в пределах ±1 % без трекинга (−0,007…+0,010 em), Onest 500 — с вопросами FAQ (±0,4 %). Отношение x-height/капитель у Onest 0,745 (референс ≈0,76; у Inter 0,709 — он заметно уже и мельче строчными).

- **Канал**: чат — серая карточка, звонок — голубая с иконкой телефона.
- **Ошибка**: розовая плашка `#FDEDEA`, заголовок `#A3261C` (в референсе красного нет — добавлен минимально).

Тёмная тема — те же роли, поверхности `#111716` / `#1A2220`, текст `#F2F5F4` / `#A9B6BB`, градиент текста светлее (`#35B9D6 → #3ED68A`).

## Отступы и сетка

Шаг 4 px: 4 · 8 · 12 · 16 · 24 · 32 · 40 · 48 · 64 · 96.

- Зазор между карточками — **16** (22 px изобр.).
- Внутренний отступ карточек — **48** большие, **32** малые, **56** тёмные (референс), в списке диалогов 28.
- Лист: поле до края окна **36** (`--cqa-gutter`, 8 на мобильном), верхние углы 64, внутренний отступ до 64.
- Шапка: отступ от краёв окна **60**, высота 64, контролы 32–40, промежутки 12.
- FAQ: строка ≈ **100** (32 + строка 36 + 32), текст с отступом 40, «+» 22 px, обводка 2 px.
- Контейнер контента 1200 px.

## Тени и глубина

Референс плоский: глубина — смена поверхностей (градиент → белый лист → серые/пастельные карточки → белые пилюли). Тени только у плавающих элементов и при наведении:

- `--cqa-shadow-1`: `0 1px 2px rgb(8 40 30 / 4%), 0 6px 20px rgb(8 40 30 / 6%)`
- `--cqa-shadow-2`: `0 2px 6px rgb(8 40 30 / 6%), 0 18px 48px rgb(8 40 30 / 10%)`
- Свечение героя: радиальный градиент `--cqa-c-glow`.

## Движение

`--cqa-dur-fast` 150 ms, `--cqa-dur` 260 ms, `--cqa-ease` `cubic-bezier(0.16, 1, 0.3, 1)`. Анимируются только `transform` и `opacity` (подсветка при наведении — через `opacity` псевдоэлемента). `prefers-reduced-motion: reduce` отключает анимации и плавную прокрутку.

## Компоненты

- **Шапка** — белая панель с нижними углами 30, знак + «CQA / Conversation Quality Analytics», разделы пилюлями (активный — серая `#F2F4F5`, «Апелляции» неактивны с меткой «скоро»), поле набора `group_id` в серой пилюле с чёрной круглой кнопкой, переключатель темы 72×36 с зелёной ручкой. Высота шапки пишется в `--cqa-header-h` (ResizeObserver) — от неё считаются все липкие элементы.
- **Герой** — на градиенте: пилюля-контекст («Набор DEV»), display-заголовок, один градиентный lead. Справа — **сводка**: белая карточка 30 px с главным числом и сложенными полосами распределений (категориальная палитра `--cqa-c-cat-1…5`: `#0091B4`, `#00BC5F`, `#6F8CCB`, `#93A2AA`, `#57BFC7`), легенда с числом и долей.
- **Лист** — белая поверхность с углами 64, внутри фильтры и данные.
- **Фильтры** — у каждой группы видимая подпись. Сегменты в сером треке, активный — чёрная пилюля (как кнопка «Подробнее»), счётчики рядом. Поиск — серая пилюля 48 px (горячая клавиша `/`). Ряд «Результат оценки» (Не оценено / Грубая ошибка / Нужна проверка / Апелляция) и «Итоговый балл» заложен заранее: пока у диалогов нет оценки, пункты неактивны с пояснением и включаются сами, когда в данных появится поле `evaluation`.
- **Таблица диалогов** — строки с разделителями 1 px (ритм FAQ референса), липкая шапка таблицы, сортировка по id / репликам / длительности (`aria-sort`). Колонки: диалог (id + канал · язык), реплики (число + мини-полоска ролей), длительность, первая реплика клиента (2 строки), оценка. Вся строка кликабельна, для клавиатуры — ссылка в первой ячейке. Под превью — место для бейджа «Грубая ошибка» с коротким объяснением. До 960 px строки складываются в блоки.
- **Статусы** (`cqa-status--*`): `pending` — пунктирный контур, «Не оценено»; `done` — мятный `#E4F3E9` / `#007A45`; `review` — жёлтый `#FFF6C7` / `#7A5B00`; `appeal` — лавандовый `#E0ECFA` / `#3D5A99`; `error` — розовый `#FDEDEA` / `#A3261C`. Везде одинаковы.
- **Транскрипт** — клиент слева (серый), оператор (мятный) и бот (голубой) справа, система — приглушённая строка по центру. Номер `#N` — якорь: `N = index + 1`, в URL (`?m=`) и `id` элемента — исходный `index` из API.
- **Плеер звонка** — тёмная карточка `#27292D`, липкая; клик по тайм-коду перематывает, текущая реплика обводится зелёным, «Следовать за записью» прокручивает транскрипт.
- **Панель «Оценка»** — серая карточка: «— / 100», секции и критерии чек-листа «не оценено» с весами, неактивная чёрная кнопка «Оценить» с пояснением.
- **Чек-лист** — аккордеон в стиле FAQ: строки с разделителями 1 px, зелёный «+» поворачивается в «×»; внутри — условия «Да» / «Нет» / N/A, ступени шкалы с пересчётом в баллы, карточка «Как считается итог».
- **Состояния** — скелетоны строк, счётчик секунд при медленном API кейса, ошибка с текстом бэкенда, кодом, «Повторить» и выходом (к DEV / к списку), пусто по фильтрам со «Сбросить фильтры», страница «не найдено» со ссылками.
