# Список фич

## Обязательные

- [ ] **1. Редактор чек-листа.** Добавить, изменить и удалить критерий; вес, тип ответа (Да/Нет или шкала), доступность N/A, ступени шкалы, секции. Сохранение версиями.
- [ ] **2. Оценка диалогов.** Оценка одного диалога и пакетная оценка набора с прогрессом.
- [ ] **3. Результат по каждому критерию.** Ответ, баллы, вес, объяснение и кликабельная реплика-доказательство. Для пропущенного действия — проверенный участок диалога, для N/A — выполненное условие неприменимости. Итог, итоги секций и отдельная отметка о грубой ошибке.
- [ ] **4. Апелляция и пересмотр.** Апелляция по критерию с комментарием → решение проверяющего с причиной → пересчёт итога. В карточке видны исходная оценка, решение и финальный результат.
- [ ] **5. Замена критерия.** Сохранение новой версии чек-листа через интерфейс и переоценка выданных диалогов.
- [ ] **6. Плеер звонков.** Прослушивание записи и переход к фрагменту из обоснования.
- [ ] **7. README.** Модель и стоимость одной оценки, запуск, архитектура, как поменять чек-лист.

## Качество оценки

- [ ] **8. Вызов модели на каждый критерий.** Строгий JSON в порядке «применимость → доказательства → вердикт». Простые проверки (приветствие и язык, подозрительные фразы для критерия 08) делаются правилами в коде и передаются модели как сигналы.
- [ ] **9. Проверка цитат кодом.** Реплика существует, роль подходит, цитата совпадает с текстом. Неподтверждённый вердикт получает статус «нужна проверка» и не идёт в балл.
- [ ] **10. Голосование.** Несколько независимых моделей или прогонов; расхождение → уровень уверенности и очередь «нужна проверка человеком».
- [ ] **11. Метрика точности.** Совпадение с ручной разметкой по каждому критерию.
- [ ] **12. Живой пересчёт.** Итог пересчитывается сразу при изменении веса или N/A.
- [ ] **13. Экспорт и стоимость.** Результаты в JSON/CSV; стоимость каждой оценки в интерфейсе.

## Дополнительные возможности

- [ ] **14. Панель точности.** Отдельно на отложенных чатах, разбивка по языкам, путаница N/A ↔ «Нет», согласие экспертов между собой как ориентир.
- [ ] **15. Песочница критерия.** Правка → прогон на размеченных чатах → изменение точности и итогов → сохранение новой версии.
- [ ] **16. Стенд Dynamics 365.** Интерфейс внутри макета формы с ограничениями платформы: относительные пути, контекст записи, строгий CSP.
- [ ] **17. Аналитика сценария.** Частота провалов по критериям, характерные цитаты, рекомендации по скрипту, доля принятых апелляций по критериям.
- [ ] **18. Несколько провайдеров моделей.** Claude, открытые модели на Cloudflare Workers AI и локальная модель; выбор в настройках и точность каждой на разметке.
- [ ] **19. Подача.** README с демо-GIF; интерфейс в визуальном стиле Freedom.
