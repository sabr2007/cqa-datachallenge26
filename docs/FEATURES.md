# Список фич

## Обязательные

- [x] **1. Редактор чек-листа.** Добавить, изменить и удалить критерий; вес, тип ответа (Да/Нет или шкала), доступность N/A, ступени шкалы, секции. Сохранение версиями.
- [x] **2. Оценка диалогов.** Оценка одного диалога и пакетная оценка набора с прогрессом.
- [x] **3. Результат по каждому критерию.** Ответ, баллы, вес, объяснение и кликабельная реплика-доказательство. Для пропущенного действия — проверенный участок диалога, для N/A — выполненное условие неприменимости. Итог, итоги секций и отдельная отметка о грубой ошибке.
- [x] **4. Фильтры по результатам.** Диалоги с грубыми ошибками — с объяснением прямо в списке; фильтры по итоговому баллу, критерию с ответом «Нет», языку, каналу, статусу апелляции и «нужна проверка».
- [x] **5. Апелляция и пересмотр.** Апелляция по критерию с комментарием → решение проверяющего с причиной → пересчёт итога. В карточке видны исходная оценка, решение и финальный результат.
- [x] **6. Замена критерия.** Сохранение новой версии чек-листа через интерфейс и переоценка выданных диалогов.
- [x] **7. Плеер звонков.** Прослушивание записи и переход к фрагменту из обоснования.
- [x] **8. README.** Модель и стоимость одной оценки, запуск, архитектура, как поменять чек-лист.

## Качество оценки

- [x] **9. Вызов модели на каждый критерий.** Строгий JSON в порядке «применимость → доказательства → вердикт». Простые проверки (приветствие и язык, подозрительные фразы для критерия 08) делаются правилами в коде и передаются модели как сигналы.
- [x] **10. Проверка цитат кодом.** Реплика существует, роль подходит, цитата совпадает с текстом. Неподтверждённый вердикт получает статус «нужна проверка» и не идёт в балл.
- [x] **11. Голосование.** Несколько независимых моделей или прогонов; расхождение → уровень уверенности и очередь «нужна проверка человеком».
- [x] **12. Метрика точности.** Совпадение с ручной разметкой по каждому критерию.
- [x] **13. Живой пересчёт.** Итог пересчитывается сразу при изменении веса или N/A.
- [x] **14. Экспорт и стоимость.** Результаты в JSON/CSV; стоимость каждой оценки в интерфейсе.

## Дополнительные возможности

- [x] **15. Панель точности.** Отдельно на отложенных чатах, разбивка по языкам, путаница N/A ↔ «Нет», согласие экспертов между собой как ориентир.
- [x] **16. Песочница критерия.** Правка → прогон на размеченных чатах → изменение точности и итогов → сохранение новой версии.
- [x] **17. Стенд Dynamics 365.** Интерфейс внутри макета формы с ограничениями платформы: относительные пути, контекст записи, строгий CSP.
- [x] **18. Аналитика сценария.** Частота провалов по критериям, характерные цитаты, рекомендации по скрипту, доля принятых апелляций по критериям.
- [x] **19. Несколько провайдеров моделей.** Claude, открытые модели на Cloudflare Workers AI и локальная модель; выбор в настройках и точность каждой на разметке.

## Демонстрация

- [x] **20. Живое демо по запросу.** Любой сценарий проходится вживую за несколько кликов: грубые ошибки с объяснениями, апелляция, изменение чек-листа (новый критерий, правка, вес), результат конкретного диалога с обоснованием.
- [x] **21. Самостоятельная работа с интерфейсом.** Понятная навигация и подсказки, внятные пустые состояния и ошибки, устойчивость к неожиданным действиям; запуск на ноутбуке и по ссылке.
- [x] **22. Подача.** Пара слайдов о решении; README с демо-GIF; сдержанный корпоративный интерфейс в визуальном стиле Freedom.
